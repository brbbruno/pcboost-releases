# PC Boost

Otimizador de PC para jogos, para Windows 11. Reúne em um app só:

- mais de 120 ajustes do Windows, todos reversíveis, com histórico e desfazer em um clique;
- modo partida, que prepara o PC sozinho quando você abre um jogo;
- perfis de configuração, limpeza de arquivos e de RAM, monitor de hardware em tempo real e testes de rede;
- debloat dos apps do Windows e controle dos recursos de IA.

Este repositório guarda só as versões prontas para baixar e o manifesto de atualização. É um projeto pessoal em teste — use por sua conta e risco e aproveite o ponto de restauração que o próprio app oferece.

## Baixar a última versão

[**Baixar PC Boost**](https://github.com/brbbruno/pcboost-releases/releases/latest) — pegue o arquivo `PCBoost-Setup.exe`.

## O aviso azul do Windows

Na primeira vez o Windows mostra "O Windows protegeu o computador". Isso acontece porque o app não tem certificado de código pago — não é sinal de vírus. Para instalar:

1. Clique em **Mais informações**.
2. Clique em **Executar assim mesmo**.

Depois de instalado, as atualizações chegam dentro do próprio app: cada versão nova é **assinada digitalmente e conferida** pelo app antes de instalar — só um pacote assinado com a chave certa é aceito.

## Requisitos

- Windows 11 (64 bits).
- Permissão de administrador na instalação (o assistente pede uma vez; o serviço auxiliar cuida do resto).

## Desinstalar

"Configurações → Aplicativos instalados → PC Boost → Desinstalar". O desinstalador pergunta se você quer reverter os ajustes feitos e se quer apagar histórico, perfis e configurações — por padrão nada disso é apagado.
